
# Student Tracking System

A simple desktop application built with Python, Tkinter,
and SQLite3.

This project was created as part of my Web & Software
Developer Diploma.

## Features

- Add students with their first name, last name, phone
  number, email, and current course.
- View all saved student records.
- Delete one or multiple selected students.
- Store student records using SQLite3.

## Technologies Used

- Python
- Tkinter
- SQLite3

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

   python3 student_main.py

Alternatively, open student_main.py in Python IDLE and
select Run > Run Module.

The application automatically creates students.db if it
does not already exist.

## Project Files

- student_main.py - Main application window.
- student_gui.py - User interface and controls.
- student_func.py - Database functions.
